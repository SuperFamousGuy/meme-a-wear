- **Stage.** I rated it `peaking` because of near-million-like compilations, explainer coverage, and KYM's statement that it peaked the week before 2026-11-20. I confirmed only one platform (TikTok), which is short of the usual three. By 2026-11-24 it may already be past its high point. Recheck before a large print run.
- **Origin conflict.** KYM credits @elisha67865 (2026-10-31). A search summary also mentioned a late-October post about throwing a fly hard enough to crack a window. I couldn't confirm that post, so `origin` uses KYM's date.
- **Crossover.** A KYM gallery item titled "Skipped 'In This Town'" jokes about skipping the `huss-town` audio. The two memes share an audience.
- **Text meme.** The format is mostly caption text, so a designer can work from the still and the example lines. Video compilations add nothing visual beyond scrolling comments.
- **Research method.** Bash denied the `last30days` wrapper. The Bluesky API returned 403. Evidence comes from KYM, web search, and Trademarkia.
- **Traits.** I wrote the traits from the KYM cover image, which I viewed. `checked_against` stays `unverified`.
