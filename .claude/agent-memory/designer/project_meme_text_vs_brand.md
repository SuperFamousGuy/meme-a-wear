Since 2026-10-26, pitches flag two recurring brand conflicts for the user to decide. (1) Caption style: brand captions are Archivo Black, all caps, eight words or fewer. But "Scientists reveal the Hi" needs a serif headline, "While they're out partying btw" needs sentence-case outlined sans, and the haunted-house template runs past eight words. (2) Palette: Ink, Chalk, Yolk, and Smoke have no ginger or pink. The pitches render ginger fur in Yolk.

**Why:** Brand guidelines are still draft. Only the user can approve exceptions.

**How to apply:** Check `brand/guidelines.md` for a decision before making artwork from those pitches. When the user rules, record it here as feedback and drop the "pending" wording.
