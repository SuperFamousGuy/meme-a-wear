Collected 2026-10-18. All figures come from third-party sources. Confirm them in the Printify editor and on Etsy's fee page.

- Etsy POD averages (Listadum, July 2026): tee $20.17, mug $17.81. Single vinyl sticker about $3-5 (RankHero, April 2026).
- Printify base: Bella+Canvas 3001 about $10.50-11 Free / $8.77 Premium; 11 oz mug $4.69-8.50 by provider, plus $4.39-7.99 shipping; 3x3 kiss-cut $1.20-1.52.
- Etsy US fees: $0.20 listing, 6.5% transaction (incl. shipping), 3% + $0.25 processing. Offsite Ads 15% when attributed.

Access: etsy.com search, etsy.com/legal/fees, redbubble.com, and teepublic.com return 403 to WebFetch. Amazon search returns 503. The Printify product pages load without prices (JS). Use WebSearch summaries and state the gap.
